A single status update, in the voice of a lost sock, for the make.fun bounty
"Funniest Lost Sock Status Update". One sock, one vending machine, one
misunderstanding with the snack crowd — 111 characters, no dryer involved.

> Update: I'm stuck in the vending machine by the chips. People press B4 hoping I'm a snack. Honestly? Flattered.

## Run it

```sh
python3 main.py
```

It writes the status update to `/output/entry.txt` (and prints it). The output
is deterministic: the same line, byte for byte, on every run.
